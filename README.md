# Cozy Crafts🧶

Official website for **Cozy Crafts at The University of Texas at Dallas**, a student organization centered around creative making and community building.  
The site communicates club information through a craft-inspired visual system while maintaining clean, maintainable frontend architecture.


## 🧩 Project Overview

This project is a static, responsive website designed to:
- Provide clear information about the club (About, Events, Officers, Contact)
- Establish a recognizable visual identity for Cozy Crafts
- Serve as a low-maintenance, easily updatable platform for a student organization
- Future goals include: linking Instagram posts directly onto the site, adding event posts, and a guest/admin view to directly edit contents of the site.
Each section uses a different craft motif (yarn, paper, beads, markers) as a **design abstraction**.
